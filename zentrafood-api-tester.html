COMO INTEGRAR COM A API
1. CORS: Certifique-se que o Flask está rodando com CORS(app) habilitado.
2. Token: Após login, o token JWT é salvo e enviado automaticamente em todas as requisições.
3. Header: Todas as rotas protegidas recebem Authorization: Bearer <token>
4. Content-Type: Requisições JSON usam Content-Type: application/json
5. Uploads: Criação de produto usa multipart/form-data (sem Content-Type manual)

Custos de Produto

Histórico de custo de producao por produto. Usado para calcular margem nos relatorios.

GET /produtos/:id/custos Historico de custos
GET /produtos/:id/custos/vigente Custo atual
POST /produtos/:id/custos Novo custo com vigencia
DELETE /produtos/:id/custos/:custo_id Remove registro de custo

Relatorios

Todos exigem ?de=YYYY-MM-DD&ate=YYYY-MM-DD. Permissao: dono, gerente, administracao.

GET /relatorios/vendas Faturamento, ticket medio, por dia, comparativo
GET /relatorios/produtos Ranking, margem bruta, representatividade
GET /relatorios/pedidos Por status, heatmap por hora, taxa de cancelamento
GET /relatorios/motoboys Entregas, km rodado, repasse, taxa de sucesso por motoboy
GET /relatorios/clientes Ranking VIP - pedidos, gasto total, ticket medio
GET /relatorios/financeiro DRE - receita bruta, custos, lucro, margem, ponto de equilibrio
