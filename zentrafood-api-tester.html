COMO INTEGRAR COM A API
1. CORS: Certifique-se que o Flask está rodando com CORS(app) habilitado.
2. Token: Após login, o token JWT é salvo e enviado automaticamente em todas as requisições.
3. Header: Todas as rotas protegidas recebem Authorization: Bearer <token>
4. Content-Type: Requisições JSON usam Content-Type: application/json
5. Uploads: Criação de produto usa multipart/form-data (sem Content-Type manual)
